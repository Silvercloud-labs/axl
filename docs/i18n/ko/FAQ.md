# FAQ — 자주 묻는 질문

---

### AXL은 오픈 소스인가요, 아니면 그냥 무료인가요?

**오픈 소스입니다.** Apache License 2.0, OSI 승인 라이선스. 읽기, 실행, 수정, 재배포, 포크, 그리고 그 위에 구축된 소프트웨어 판매 — 상업적으로, 허가 없이, 무료로 할 수 있습니다.

오픈 코어 분리, 유료 티어, 텔레메트리, 제한된 기능 — 전혀 없습니다. 컴파일러, 런타임 엔진, CLI, 생성기, VS Code 확장 전체 도구 체인이 이 저장소에 있습니다.

### 왜 MIT가 아닌 Apache 2.0인가요?

| | MIT | Apache 2.0 |
|---|---|---|
| 자유롭게 사용·수정·판매 | 예 | 예 |
| 명시적 특허 허가 | 아니오 | 예 |
| 이름 상표 보호 | 아니오 | 예 |
| 변경 사항 명시 필요 | 아니오 | 예 |

### 프로덕션 환경에 사용할 수 있나요?

**아직 아닙니다. 솔직히 말하면 아무것도 배포된 적이 없습니다.**

| | 상태 |
|---|---|
| 컴파일러, 런타임, CLI | 작동 중, 750개 테스트 통과 |
| npm 게시 | 아니오. 첫 번째 릴리즈 아직 미게시 |
| VS Code 확장 마켓플레이스 | 아니오. 소스에서 빌드하세요 |
| 프로덕션 사용 이력 | 알려진 바 없음 |

### AXL이 하지 않는 것은 무엇인가요?

| 범위 외 | 이유 |
|---|---|
| 인증, 결제, ID 인프라 | 백엔드 문제. AXL은 자격증명을 발행·저장·검증하지 않음 |
| OAuth 통합 | 완전히 백엔드 소유 |
| 데이터베이스 또는 ORM | AXL은 도메인 데이터를 보유하지 않음 |
| 전체 MCP 동등성 | Prompts, Notifications, Progress tracking, Roots 없음 |
| 애플리케이션 코드 분석 | `axl adapt`는 API 사양을 읽음 |
| 보상 트랜잭션 | 실패한 워크플로우는 완료된 단계를 롤백하지 않음 |

### 백엔드를 다시 작성해야 하나요?

아니오. AXL은 절대 백엔드를 대체하지 않습니다 — 앞에 위치하여 HTTP로 호출합니다.
